# RDB MiniCity · 微缩城市生成器

**RDB MiniCity · 锐多宝出品** —— 把你的城市，做成掌心里的微缩模型。

锐多宝 RDB 自有品牌产品。输入真实城市地点，拉取 OpenStreetMap 建筑、道路、水系、绿地数据，在浏览器里生成可旋转缩放的微缩 3D 城市，可换配色、导出高清图、生成分享链接。全部代码从零手写；第三方库只用 Three.js 与 Leaflet，且已下载到本地 `vendor/`，部署后不依赖境外 CDN。

品牌标为自绘 SVG（`assets/brand.svg`，favicon 同源 `assets/favicon.svg`）：深黛蓝 `#173F5F` 圆角方底、白色轨道弧线环绕朱砂 `#C8442C` 定位点、青绿 `#2E7D6B` 点缀，中央字母 M。页面页眉、导出水印与 favicon 统一使用这一视觉。

## 功能
- 中文地名搜索（地理编码服务）+ 6 个国内城市快捷预设（成都春熙路、上海陆家嘴、北京故宫、西安钟楼、杭州西湖断桥、深圳市民中心）+ Leaflet 小地图点选/框选预览
- 范围边长 200 / 400 / 800 米可选
- 数据层：建筑（含高度、层数标签）、道路、水系、绿地；高度缺失时按「层数 × 3.2 米」或按建筑编号哈希的确定性估算，同一地点每次一致
- 坐标：手写本地墨卡托投影，转米制平面坐标
- 场景：建筑拉伸体块 + 收分屋顶 + 描边、道路带、水面半透明面、绿地色块、双层方形底座、平行光阴影、正交相机等距视角、轨道旋转缩放
- 配色 6 套：青绿山水（青绿山水——取色千里江山，石青石绿入城）、宣纸朱砂（宣纸朱砂——宣纸为底，朱砂点城）、现代浅色、夜景霓虹、蓝图、暮色陶土
- 导出 PNG：2048px 与 4096px 两档；免费版 2048px 带品牌水印、4096px 锁定，Pro 去水印并解锁 4096px（授权方式见下）
- 分享链接：视角、主题、地点、范围编码进 URL hash，打开即还原（分享链接不携带授权状态）
- 界面全中文，移动端基本可用
- **生成阶段提示（整改阶段一新增）**：生成过程分「查询中（第几路/已等待秒数）→解析中→建模中」实时显示，上游繁忙时给出 1–2 分钟的等待预期；生成完成显示总用时
- **点击建筑看详情（整改阶段一新增）**：单击任意建筑（拖动旋转不触发），状态栏显示建筑名称与高度，并如实标注高度来源（开放街图标签 / 按层数推算 / 估算）
- **服务端缓存降级（整改阶段一新增）**：本地服务对查询结果做磁盘缓存，响应头 `X-RDB-Cache` 标注 hit/miss/stale；上游失败且有过期缓存时降级返回旧数据（stale）而不是直接报错；另有 `GET /api/health`（含缓存条数）与缓存预热脚本 `tools/prewarm_cache.py`（部署后把 6 个预设地点×常用范围提前打入缓存）

## 授权激活（HMAC-SHA256 授权码）

与锐多宝其他产品同一自有方案：授权码形如 `RDBMC-<载荷>-<签名>`，载荷为含邮箱、plan（monthly / permanent）、到期日的紧凑 JSON，Base32 编码后按 5 字符分组；签名为 HMAC-SHA256(密钥, 载荷字节) 的前 20 字节再 Base32 分组。monthly 带到期日（含到期日当天可用，过期拒绝），permanent 无到期日。

- 验签接口：`POST /api/activate`，请求体 `{"code": "RDBMC-…"}`，成功返回 `{"ok": true, "pro": true, "plan": …, "email": …, "exp": …}`，失败返回 403 与中文原因。
- 前端：页面「授权与版本」区输入授权码激活，结果存浏览器 localStorage；刷新后自动复验（连不上后端时保留本地记录作离线宽限，服务端明确拒绝则降级免费版）。Pro 状态只认本机激活记录，分享链接不能传递 Pro。
- 发码（运营方）：先 `export RDBMC_SECRET='<真实密钥>'`，再运行
  - 月付：`python3 tools/issue_license.py --email user@example.com --plan monthly --days 30`
  - 永久：`python3 tools/issue_license.py --email user@example.com --plan permanent`
  脚本签发后会自验回读并打印载荷摘要，确认无误再把码发给用户。
- 密钥：从环境变量 `RDBMC_SECRET` 读取；未设置时使用仓库中的示例假密钥（`license.py` 内 `EXAMPLE_DEV_SECRET`，仅供本地开发与测试）。**上线前必须更换为随机长密钥**，切勿把真实密钥写进代码、仓库或页面。

## 本地运行
```bash
# 推荐：带代理、缓存与授权接口的本地服务
python3 server.py 8765        # 打开 http://127.0.0.1:8765/

# 或纯静态（前端直连公开接口；此模式下无法调用 /api/activate 激活）
python3 -m http.server 8000   # 打开 http://127.0.0.1:8000/
```
测试：`node --test tests/run.test.mjs`（Node 20+，逻辑 6 项）；`python3 tests/test_license.py`（授权签发/验签/接口测试）。

## 部署方式
把整个目录放到任意静态托管即可运行免费版；如需同源代理、磁盘缓存与授权激活，把 `server.py` 以常驻进程运行并反向代理到它，无额外依赖（Python 标准库），并为其设置环境变量 `RDBMC_SECRET`（真实密钥）。

## 目录
- `index.html` 页面入口 · `css/` 样式 · `js/` 投影/数据/主题/场景/分享/应用逻辑
- `assets/` 自绘品牌标与 favicon（SVG）· `vendor/` Three.js 与 Leaflet 本地发行文件
- `fixtures/` 测试样例数据 · `tests/` Node 无头测试与授权测试
- `license.py` 授权码签发/验签模块 · `tools/issue_license.py` 发码脚本
- `skill/` 智能体调用说明包 · `server.py` 可选后端（静态托管 + 代理 + /api/activate）

## 已知局限
- **国内 OpenStreetMap 建筑覆盖不全**：不少城市只有主干道路、缺建筑轮廓，生成结果会偏空；海外城市与国内核心城区数据较完整。这是数据源局限，不是程序错误，界面里已如实提示。
- 建筑高度多为估算值，不是实测；个别自交多边形建筑会被跳过。
- 地理编码与数据查询依赖公开服务的可用性与限速，本地服务已做磁盘缓存以减少重复请求。
- 授权为单机校验：激活结果保存在用户浏览器 localStorage，清缓存或换设备需重新输入授权码；无账号体系与多设备同步。
- 纯静态部署（无 server.py）时无法激活 Pro。
